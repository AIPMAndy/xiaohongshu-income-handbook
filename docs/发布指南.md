# 发布到 GitHub 的最短流程

**目标仓库：** `AIPMAndy/xiaohongshu-income-handbook`  
**网站地址：** `https://aipmandy.github.io/xiaohongshu-income-handbook/`

1. 在 https://github.com/new 创建公开仓库，Repository name 填写 `xiaohongshu-income-handbook`；取消勾选预生成 README / .gitignore / License（本包已经包含）。
2. 本地解压本包，进入 `xiaohongshu-income-handbook` 文件夹；电脑先安装 Git、GitHub CLI 并登录 `gh auth login`。
3. 执行 `bash scripts/publish.sh`；脚本先校验源码，然后创建/连接 GitHub 远端并推送 main。
4. 进入 GitHub 仓库 `Settings → Pages → Source` 选择 `GitHub Actions`，随后到 `Actions` 检查 `Pages` 工作流是否成功。
5. 打开在线教程，逐项验证章节、路线选择、进度保存、利润计算、Markdown/CSV 下载与手机适配。

**注意：** 只有当 GitHub 显示 Public、Pages 部署成功、站点可访问时，才能在对外材料中声称“已开源上线”。
